# Local fonts

Fetched 2026-11-14 from the Google Fonts repository, under SIL Open Font License 1.1:

- `Inter.ttf`: `google/fonts/ofl/inter/Inter[opsz,wght].ttf`
- `JetBrainsMono.ttf`: `google/fonts/ofl/jetbrainsmono/JetBrainsMono[wght].ttf`
- `Outfit.ttf`: `google/fonts/ofl/outfit/Outfit[wght].ttf`

The corresponding `*-OFL.txt` files are included. Source URL prefix:
`https://raw.githubusercontent.com/google/fonts/main/`.

Vite embeds these local files in the built CSS; runtime never requests a font CDN.
